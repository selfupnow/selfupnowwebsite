# SelfUpNow Website

A responsive, minimal website for SelfUpNow built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Files
- `index.html` — full website.
- `portfolio.pdf` — add your actual portfolio PDF here (not included because the portfolio document has not been supplied).

## Run locally
Double-click `index.html` or open it in a browser. For local development, you can also use VS Code's Live Server extension.

## Before publishing
1. In `index.html`, change `AGENCY_EMAIL = "hello@selfupnow.com"` to your real business email.
2. Add your portfolio PDF as `portfolio.pdf` in the same folder, or change the links that currently point to `portfolio.pdf` to your hosted PDF URL.
3. Connect the application form to a real form backend (Formspree, Basin, or your own backend) if you want submissions without requiring the visitor's email app. The current form opens a prefilled email.
4. Confirm package deliverables and prices before publishing.
5. Replace the example email/domain in metadata if needed.
6. Deploy the folder to a static host such as Netlify, Vercel, or GitHub Pages.
